# Bundespolizei-Aktensystem (RP-Demo)

## Start
1. Alle drei Dateien im selben Ordner lassen.
2. `index.html` im Browser öffnen (oder VS Code Live Server verwenden).
3. Standardpasswort: `BP-RP-2026`. In `script.js` über DEFAULT_PASSWORD ändern.

## Enthalten
- Dashboard, Akten anlegen/bearbeiten/suchen/löschen
- Personenverwaltung
- Beweismittel-/Dokumenteinträge
- Speicherung mit localStorage

## Grenzen
- Speicherung nur im aktuellen Browser auf dem jeweiligen Gerät.
- Passwort im JavaScript ist keine echte Sicherheit.
- Keine echten vertraulichen Daten verwenden.
- Dateinamen/Verweise werden gespeichert, aber Dateien nicht hochgeladen.
- Keine gemeinsame Speicherung über mehrere PCs.
